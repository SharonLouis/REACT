# React Mini Projects 🚀

A collection of small React projects built while learning and practicing React fundamentals. These mini-projects helped me understand concepts such as components, props, state management, event handling, hooks, conditional rendering, and working with APIs.

## 📂 Projects

- **BasicCounter** – A simple counter application to practice state and event handling.
- **ColorChanger** – A color-changing application to understand state updates and dynamic styling.
- **Learn** – A collection of React learning/practice concepts and experiments.
- **Password Generator** – Generates secure random passwords with customizable options.
- **Todo App** – A simple task management application to practice CRUD operations and state management.
- **ViteReact** – A basic React project created using Vite to explore the React development setup.

## 🛠️ Tech Stack

- React.js
- JavaScript
- HTML5
- CSS3
- Vite

## 🎯 Purpose

This repository contains my React practice projects and serves as a record of my progress while learning React and building applications from scratch.
